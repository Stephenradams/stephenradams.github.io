# Projects

<p class="projects-intro">A selection of notable projects from my career as a freelance frontend developer — spanning fintech, biotech, telecoms, and tooling.</p>

<div class="projects-grid">

<div class="project-card">
  <div class="project-header">
    <span class="project-icon">🧬</span>
    <div class="project-meta">
      <h3>AlphaFold Server</h3>
      <span class="project-client">Google DeepMind</span>
      <span class="project-tech">Angular · TypeScript · Google standards</span>
    </div>
  </div>
  <p>Worked on the web application for DeepMind's globally used research tool for protein structure prediction. Built new features and maintained the production codebase as part of a small team.</p>
  <ul class="project-list">
    <li>Migrated all site content from hard-coded HTML to Markdown sourced from Google Docs</li>
    <li>Built an image zoom feature in the Guide section to aid navigation</li>
    <li>Developed and shipped features to Google's internal Angular and TypeScript standards</li>
  </ul>
</div>

<div class="project-card">
  <div class="project-header">
    <span class="project-icon">🗺️</span>
    <div class="project-meta">
      <h3>Sports TV Network Map</h3>
      <span class="project-client">BT</span>
      <span class="project-tech">React · LeafletJS · GraphQL · REST</span>
    </div>
  </div>
  <p>Sole frontend developer on an internal tooling project to visualise BT's Sports TV network infrastructure across the UK. Engineers used it to check existing cable connections before commissioning new work, preventing costly redundant projects.</p>
  <ul class="project-list">
    <li>Built an interactive map with LeafletJS rendering cable lines and point detail</li>
    <li>Integrated REST and GraphQL APIs to load and display large datasets</li>
    <li>Optimised search using local storage for internal codes to keep performance fast</li>
    <li>Extended BT's internal React component library to follow brand guidelines</li>
  </ul>
</div>

<div class="project-card">
  <div class="project-header">
    <span class="project-icon">🖥️</span>
    <div class="project-meta">
      <h3>Reseller Workspace App</h3>
      <span class="project-client">RealWear</span>
      <span class="project-tech">Angular · TypeScript · NX mono-repo</span>
    </div>
  </div>
  <p>Built an application for RealWear's reseller network to manage client workspaces and oversee headset fleets, as part of a broader effort to standardise UI across all RealWear products.</p>
  <ul class="project-list">
    <li>Developed the workspace management feature from scratch</li>
    <li>Created a shared component library used across all RealWear web applications</li>
    <li>Set up Storybook for building, testing, and documenting components</li>
    <li>Implemented Jest for unit tests and Cypress for E2E tests</li>
  </ul>
</div>

<div class="project-card">
  <div class="project-header">
    <span class="project-icon">📹</span>
    <div class="project-meta">
      <h3>Twilio Video Call Web App</h3>
      <span class="project-client">RealWear</span>
      <span class="project-tech">Angular · Twilio · TypeScript</span>
    </div>
  </div>
  <p>Web application enabling three-way video calls between RealWear headsets and mobile devices. The project directly contributed to increased headset sales by enhancing the user experience for RealWear's customers.</p>
  <ul class="project-list">
    <li>Integrated Twilio's video SDK to support multi-party calls</li>
    <li>Built responsive UI for both mobile and desktop viewpoints</li>
    <li>Delivered as part of NX mono-repo alongside other RealWear applications</li>
  </ul>
</div>

<div class="project-card">
  <div class="project-header">
    <span class="project-icon">🤖</span>
    <div class="project-meta">
      <h3>AI Document Review Apps</h3>
      <span class="project-client">RehabAgency</span>
      <span class="project-tech">Angular 17 · TypeScript · SCSS · GCP</span>
    </div>
  </div>
  <p>Took over frontend development of three AI-powered applications for a major client. The apps allow users to enter document overviews and receive AI-generated alternatives and considerations for their reports.</p>
  <ul class="project-list">
    <li>Matched UI implementation precisely to the client's global branding</li>
    <li>Deployed all three applications on Google Cloud Platform</li>
    <li>Delivered within a tight deadline with no prior handover</li>
  </ul>
</div>

<div class="project-card">
  <div class="project-header">

  </div>

    <li>Implemented a role-based training plan system to control module access</li>
    <li>Added screen reader support and user-customisable CSS themes</li>
    <li>Mentored a junior developer throughout the engagement</li>
  </ul>
</div>

<div class="project-card">
