# Starting to learn Rust 

## Why Rust

I've mainly worked as a frontend developer building web applications using Html, CSS and JavaScript, that's been the main 'stack' for the applications I've developed over the years. It's been fun, I've built some cool things and I've enjoyed using this approach for a while now.

But as time has gone on and with the rise of AI building applications with just Html, CSS and JavaScript/TypeScript is not as appealing to me so for the last few months I've been looking for a new language to become my main programming language.

I've looked into languages such as Kotlin and Python, but I have decided that I'm going to focus on *Rust*. 

Now Rust is extremely popular it's seems everyday Rust is being chosen to be the language an existing system or tool is being rewritten in or some internet guru is spouting that they will only use Rust (which is exactly what I'm going in this post but I'm no internet guru) it looks like everything is turning to Rust so am I just jumping on the bandwagon?

Well, no the main reasons I want to work with Rust are:

  1. It's a typed language, I prefer a typed language (I always liked TypeScript over JavaScript)
  2. It forces you to write good code, there's no getting past the compiler
  3. I want a language that I know when I have written and compiled the code it works. Rust helps remove the worry of 'am I 100% sure this works'.
  4. It's versatile I can use it to write CLIs, web services, GUIs, AI services, web apps and even embedded systems if I wanted. 
  5. It's been around for a while and getting more and more popular so investing the time to learn it is worth while, it's going to be around for years to come (unless the AI apocalypse ends everything)

These are the main reasons why I have decided to learn Rust, but how will I go about it. 

## My Learning Plan

My plan for learning Rust is to learn the basic syntax and concepts then start working on a demo project, it's a classic approach but it works.  Here's a breakdown of my plan:

1. Work through Rustlings examples to learn the basic syntax (https://github.com/rust-lang/rustlings/)
2. Read the Rust book (https://doc.rust-lang.org/book/)
3. Read The Secrets of Rust: Tools by John Arundel (https://bitfieldconsulting.com/books/rust-tools)
4. Work on small projects getting use to writing Rust
5. Work on a larger project that represents more of a real-world example application
6. Repeat steps 4 and 5
